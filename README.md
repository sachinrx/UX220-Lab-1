# The Favourite thing i wrote
 

Hello my name is Sachin. A birthday message for a loved one is one of my favorite thing I've ever written. I had enjoyed writing it since it let me share some of our shared memories and tell them how much I valued having that person in my life.

Because it was honest, it was my favorite. I remembered pausing infront of everyone to ensure that it sounded like something I would actually say.
